# Contributing

This is a paused, experimental Build in Public source project. The NS device is lent out; maintainer development and native-device validation are paused. Community issues and PRs are welcome under the documented scope, but no response schedule is promised. The maintainer approved the own-code MIT grant on 2026-10-12; third-party notices retain their own terms.

For a review, identify the source commit or current manifest and describe the smallest reproducible issue using synthetic inputs. Separate software behavior, format observations and actual native-game evidence. Keep unknown fields unchanged, preserve numeric fallback and original files, and never promote gameplay validity from checksum/re-read/synthetic results alone.

Do not submit private saves, game catalogs, screenshots with player details, extracted game binaries, keys, reference archives, personal paths or unlicensed editor code. A public report should contain a sanitized symptom and synthetic reproducer, not a private file attachment. Contact details and a private reporting channel must be chosen by the maintainer before publication; none are invented here.

Before proposing imported code/data/assets, document the exact upstream URL/commit, license, notices, intended use and modifications. Attribution alone does not grant missing rights. Retain historical REE exposure, GPT assistance and isolation limitations; do not remove these statements or relabel the project all-original/clean-room.

Application changes require a separate scope and design review while development is paused. Documentation, license and source-boundary review do not authorize device operations, uploads or saves. Contributions to the MIT own-code portion are offered under that project license; imported third-party content still requires its own documented permission and notices.

The advertised catalog-independent CI suites are listed in README.md. Do not run resource-dependent or real-save workflows in public CI, and do not add catalog downloads or deployment credentials to the current workflow.
