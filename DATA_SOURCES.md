## Normalization facts

Item numeric IDs and localized names are paired directly by item.html data-sort entries. Steam typed enum offsets used for remaining classes are documented in pinned src/rsz/skill.rs, weapon.rs and armor.rs. Skill base indices start at raw 1; MR skill indices start at raw 112 and message indices 200. Decoration base indices start at raw 1; MR starts at raw109 and message200. Weapon and armor types use distinct high-bit ID ranges. Rejected or missing name entries are excluded. These are external-output decoding facts, not permission to write NS fields.

Full URLs for definitions: https://github.com/wwylele/mhrice/tree/bc8ef84a0fc61aad079e7ae1fcabd8a188212538/src/rsz . Exact individual filenames and SHA-256 values, website/source inputs and normalized catalog hash are recorded in data/mhrice/source-hashes.json. Website output is hash-pinned separately: do not pretend it was generated by today's repository HEAD.

Counts: Item 1771; Skill 147; Decoration 244; Weapon 3953; Armor 1560. Only en and zh-CN name strings retained. Rule-like slot values are claims for display/filtering, never an NS write authority.

## Local provider

LocalGameCatalogProvider currently consumes an explicitly selected, documented catalog.json. It does not yet extract .msg or game archives. Local JSON claims cannot self-certify NS mappings. A verified-local route needs separately reviewed evidence. No user game files or old catalog are bundled.

## R10 reference parameters and offline build planning (2026-10-05)

The existing hash-pinned output is now also normalized into reference parameters for 3953 weapons, 1560 armor entries, 244 decorations and 147 skills. No IDs, names or categories were changed. Added values are weapon base attack/affinity/defense bonus/element, armor base defense/resistances/skills, displayed rarity, base slots, decoration skill contributions and declared skill maxima. There are still zero verified NS mappings.

Official raw files at the actual website-generator commit were fetched again for this extension. `data/mhrice/parameter-sources.json` identifies each exact URL, commit and SHA-256, the prior output hash, normalization rules and resulting catalog hash. It does not claim a fresh extraction from a user's game. The first R8 source-hash manifest contained malformed reference URLs with an extra `reference` path; the R10 update corrects those links only after comparison with the fetched official file bytes. Earlier Git history retains the prior manifest.

Normalization facts: the output rarity wrapper already includes its displayed offset; no extra +1 is applied. Skill maximum values use a zero-based enumeration and are normalized by +1. Armor/decorations skill contribution levels are direct values. Base-slot arrays are histograms: index 0 counts level-1 slots, through index 3 for level-4 slots; the normalized three positions are sorted descending and padded with zero. They describe base catalog equipment, not actual augmented save slots. Seven armor placeholder skill entries have nonzero stored level but no skill ID; they are excluded from contributions, matching the published generator's nonempty-ID interpretation, and are counted in the extraction record.

These values may drive an offline plan, slot filtering and a clearly labeled base-attribute preview. They do not establish legal NS talismans, actual socket order/capacity, augmentation effects, inventory accounting, upgrade maxima or permission to expand any save-write limit. The planner does not create or equip game items. MHRice/Capcom attribution and existing scope qualifications remain applicable.
