# Catalog content excluded

This proposed source-only public snapshot does not contain `catalog.json`, game-derived names/parameters, raw MHRice output, or any private save. The two retained JSON files are historical source-identity/normalization records, not catalog payloads. Their references and digests are not evidence that those inputs are bundled or licensed by the game rightsholder.

The desktop can compile without the optional file and retains its existing numeric fallback. Build planning opens without a save, but selecting real reference equipment/name candidates requires a separately supplied lawful local catalog. This preparation does not download one or fabricate name/parameter coverage.
