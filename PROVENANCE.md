# Provenance of this preview

## Source baseline and history

The source baseline is the independently implemented R10 project, branch `clean/foundation`, commit `f041cdc8408e9eadc88b05fb95d884e25a8d1198`. The legacy v2.10.11 RC1 OpenSource package is a different implementation line and is not this project's version or legal/validation baseline. Its historical record of 83 tests is not imported as a fresh R10 result.

The original R10 history remains intact locally. The maintainer approved NEW public repository history from this explicit allowlisted snapshot on 2026-10-12. The original history includes actual game catalog content and remains blocked for an ordinary push under the publication exclusions. It was not rewritten or imported into this new history; see PUBLICATION_BOUNDARY.md.

Original admitted-input manifests, source snapshots, isolation notes and MHRice source-identity/normalization records remain as historical evidence. A digest identifies bytes, not ownership or an authenticated discovery chronology. `source-snapshot-r10-review.json` covers 44 original source/project files; its hashes were checked against the original before staging. The optional-resource Desktop project-copy guard changes one project file in this preview, so that historical record is not a current hash manifest. Current file hashes are in MANIFEST.sha256.json.

## Third-party boundaries

MHRice by Weiyi Wang is separately attributed, with the full MIT notice in `licenses/MHRice-MIT.txt` and exact historical inputs/commits in DATA_SOURCES.md, `data/mhrice/source-hashes.json` and `data/mhrice/parameter-sources.json`. Actual generated catalog content is excluded. No MHRice Rust or website implementation is compiled into this R10 application. The six Rust files in the legacy line were not imported into this independent snapshot; their unrelated license/audit results are not presented as new R10 implementation evidence.

MurmurHash3 x86_32 is Austin Appleby's existing public-domain algorithm; it is not this project's invention. .NET APIs and Deflate are external platform/format dependencies. This source preview ships neither a .NET runtime/SDK nor game binary assets. MHRice's permission and the approved project MIT grant do not relicense Capcom/Nintendo material or cure other missing permission.

The maintainer approved the own-code MIT grant on 2026-10-12 for material the publisher is entitled to license; third-party and game-content boundaries remain separate. Neither the old engineering disposition labels nor a lexical no-match result supplies blanket legal clearance. No all-original, zero-risk or stable-release claim is made.
